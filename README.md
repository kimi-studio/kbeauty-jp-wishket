## 🎯 プロジェクト概要

このプロトタイプは、日本人観光客が韓国で美容・エンターテインメント体験（メイクアップ、ダンス、ボーカル、パーソナルカラー診断、ガイド、衣装レンタル、撮影）を簡単に予約できるモバイルアプリケーションのデザインコンセプトです。

### 主な改善点（v5）

1. **UX重視の設計**
   - 信頼性の可視化（日本語サポート保証、レビュー重視）
   - 価格透明性（メニュー別明細、手数料明示）
   - 予約フロー最適化（3ステップ+進捗表示）
   - 不安解消（予約確定前の安心メッセージ、決済セキュリティ表示）

2. **日本語ファースト**
   - 全コンテンツが自然な日本語
   - 日本人ユーザー向けUI/UXパターン
   - 安心感を重視したコピーライティング

3. **視覚的完成度**
   - モダンなカラーシステム（Purple系メインカラー）
   - 統一されたコンポーネントデザイン
   - プロフェッショナルなタイポグラフィ
   - モバイルファーストのレスポンシブ設計

4. **ビジネスKPI向上設計**
   - ポートフォリオセクションで信頼構築
   - レビュー機能で社会的証明
   - オプション追加でアップセル
   - ブックマーク・リピート導線

## 📱 含まれる画面

### コア体験フロー
1. **ホーム** — カテゴリー探索 + おすすめエキスパート
2. **検索/リスト** — フィルタリング可能なエキスパート一覧
3. **詳細** — プロフィール、ポートフォリオ、メニュー、レビュー
4. **予約（1/3）** — 日時・人数選択
5. **予約（2/3）** — 内容確認とオプション追加
6. **予約（3/3）** — 決済方法選択
7. **確認** — 予約完了画面
8. **予約管理** — 次の予約・過去の予約
9. **プロフィール** — アカウント設定

### Figmaへのインポート方法

1. Figmaで新規ファイルを作成
2. File → Import → 各SVGファイルを選択
3. 各画面が個別のフレームとして読み込まれます
4. 推奨フレームサイズ: 430×932px

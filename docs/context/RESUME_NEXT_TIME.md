# RESUME_NEXT_TIME.md

## Resume goal
When restarting this project, do **not** start from scratch.
The repo already contains a usable prototype and import assets.

## First things to check
1. Open `README.md`
2. Open `result.md`
3. Open `PROJECT_CONTEXT.md`
4. Open `index.html` locally and review the current flow
5. Check whether the Vercel deployment already reflects the latest local state
6. Check whether the manually uploaded Figma board still exists and how the SVGs were arranged

## Fast resume checklist
- [ ] Confirm current primary goal:
  - proposal polish?
  - UX revision?
  - client-facing design cleanup?
  - implementation planning?
- [ ] Decide whether Figma matters for this phase
- [ ] If not, iterate in code first
- [ ] If yes, use existing `figma_export/` assets rather than rebuilding screens manually
- [ ] Identify the 3 screens that matter most:
  - Home
  - Detail
  - Booking/Payment

## If the next phase is proposal polish
Focus on:
- stronger K-beauty positioning
- clearer trust and review proof
- tighter before/after or portfolio framing
- better premium / Japan-friendly copy
- stronger visual hierarchy on home and detail pages

## If the next phase is Figma cleanup

### Row 1 — core conversion flow
- Home

### Row 2 — post-booking/supporting screens

Open questions to settle:
- Is this specifically K-beauty tourism / concierge?
- Is it more marketplace, clinic discovery, or booking assistant?
- Should the visual direction be premium clinic, trend-driven beauty, or concierge style?
